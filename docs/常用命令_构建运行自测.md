# 舆见 OpinionLens · 常用命令清单

> 所有命令默认在 PowerShell 7 中执行，工作目录为仓库根目录。

## 0. 先设置路径变量

```powershell
$Repo = (Get-Location).Path          # 仓库根目录
$Py   = Join-Path $Repo 'MediaCrawler\.venv\Scripts\python.exe'
```

---

## 1. 安装/更新采集引擎

```powershell
.\scripts\setup_mediacrawler.ps1
```

- 克隆 MediaCrawler 固定 commit 到 `.\MediaCrawler` 并执行 `uv sync`（首次约 3–5 分钟）；
- **目录名与位置固定为 `<仓库根>\MediaCrawler`**：`app/scripts/dev.ps1`、`app/scripts/run_sidecar.ps1`、
  `app/desktop/main.js` 都硬编码了 `MediaCrawler\.venv\Scripts\python.exe`（该 venv 同时是 sidecar 的运行时），
  改名/挪位/另建 `pip install` 环境都会导致「服务在线」永远不亮（可用 `MC_PYTHON` / `MC_ROOT` 覆盖）；
- 上游 `pyproject.toml` 默认索引为清华源，实测部分 wheel 返回 403，脚本会自动改用备用索引重试；
  需要手动处理时：

  ```powershell
  cd MediaCrawler
  uv sync --default-index https://mirrors.aliyun.com/pypi/simple   # 或 https://pypi.org/simple
  ```
- 需要重装时先删除 `MediaCrawler\` 目录（注意其中可能保存登录态与采集数据）；
- MediaCrawler 为非商业学习许可，仅供个人学习研究使用，详见根目录 `THIRD_PARTY_NOTICES.md`。

## 2. 启动桌面开发版

```powershell
cd $Repo
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
.\app\scripts\dev.ps1
```

等价 npm 方式：

```powershell
cd $Repo\app\desktop
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
npm start                  # 正常启动（带 sidecar）
npm run dev                # 调试模式
npm run start:no-sidecar   # 只开 UI，不启动 sidecar
```

只启动 sidecar（调试；固定 token=devtoken，便于 curl 调试）：

```powershell
.\app\scripts\run_sidecar.ps1
```

静态 UI Mock 预览（不连 sidecar）：

```powershell
Start-Process "$Repo\app\desktop\renderer\index.html"
```

> AI 报告为可选能力：未配置模型 API 或调用失败时，报告中心自动使用本地模板生成（`degraded`），
> 不影响采集与导出。模型 API 配置见 `app/README.md` 与「设置 → 模型 API」。

## 3. 自测

### 全部自测

```powershell
.\app\scripts\selftest.ps1
```

包含：Engine patch/事件、Sidecar API、Excel 导出器、报告数据包/本地模板、新功能（通知/模型 API/账号池）、Electron 截图等离线断言（不联网）。

### 单独跑

```powershell
# sidecar 全链路自测（含新功能 phase0 单测）
& $Py "$Repo\app\sidecar\selftest.py"

# 引擎自测
& $Py "$Repo\app\engine\test_engine.py"

# 新功能离线测试
& $Py "$Repo\app\sidecar\test_notify.py"        # 通知通道/outbox/重试/脱敏
& $Py "$Repo\app\sidecar\test_llm.py"           # 模型 API provider/协议/报告直连/降级
& $Py "$Repo\app\sidecar\test_account_pool.py"  # 多账号号池/选号/切号/API

# 报告数据包 / Excel 导出
& $Py "$Repo\app\sidecar\test_report_data.py"
& $Py "$Repo\app\sidecar\test_exporter.py"
```

### 界面截图（设置页 / 多账号）

```powershell
# 真实 sidecar + Electron 截图（开发辅助参数，见 app/CONTRACT.md §4.1）
cd "$Repo\app\desktop"
.\node_modules\.bin\electron.cmd . --screenshot "$Repo\docs\preview\77_settings_model_api.png" --demo-page settings
```

> 无 Electron 环境时可用浏览器打开 `app/desktop/renderer/index.html`（无 preload 时自动进入静态预览模式）。

### 重新生成应用图标（品牌视觉）

```powershell
# 由 app/scripts/make_app_icons.py 生成 assets 下的 app-icon-1024.png / app-icon.ico
& $Py "$Repo\app\scripts\make_app_icons.py"
```

> 图标设计为「透镜 + 观察波纹」深海青品牌图形；修改配色/图形后重新运行即可，安装包与窗口图标会同步使用。

### GitHub Actions CI（离线）

push / PR 到 `main` 时自动运行 `.github/workflows/ci.yml`（Windows runner）：

- `python -m compileall -q app`、JS `node --check`；
- 5 个离线测试套件：`test_notify.py` / `test_llm.py` / `test_account_pool.py` /
  `test_report_data.py` / `test_exporter.py`；
- sidecar 全链路 `selftest.py`（fake engine + fake LLM，不联网、不启动真实浏览器）。

CI 不安装 MediaCrawler；引擎自测（`app/engine/test_engine.py`）需本地先跑 `scripts/setup_mediacrawler.ps1`。
CI 所需 Python 依赖见 [`requirements-dev.txt`](../requirements-dev.txt)，本地也可用任意 Python 3.11+
`pip install -r requirements-dev.txt` 后跑 sidecar 测试。

## 4. 生成安装前 resources staging

运行时资源（便携 Python、sidecar、engine、MediaCrawler、报告管线）必须先进入 staging：

```powershell
cd $Repo

# 运行时没变，只更新代码/模板/引擎：最快
.\app\scripts\build_pack_resources.ps1 -SkipRuntime

# 完整重建（含便携 Python）
.\app\scripts\build_pack_resources.ps1 -Clean
```

staging 输出：

```text
build\installer\resources\
```

> 报告统计/模板管线（`app/report_pipeline`）尚在迁移中：打包脚本对该目录做**存在性容错**，
> 缺失时只告警不中断；迁移完成后会自动打入安装包。

## 5. 编译 NSIS 安装包

```powershell
cd $Repo

# 推荐：只编译，不做静默安装验证
.\app\scripts\build_installer.ps1 -SkipResources -SkipVerify

.\app\scripts\build_installer.ps1 -Clean
```

产物：


```powershell
$env:ELECTRON_MIRROR = 'https://npmmirror.com/mirrors/electron/'
```

```powershell
$setup = "$Repo\build\installer\output\OpinionLens-Setup-0.1.0.exe"
```

## 6. 编译便携版

便携版不需要 NSIS 安装器，解压即用；用户数据仍在：

```text
%APPDATA%\OpinionLens
```

### 第一步：先更新 staging

```powershell
cd $Repo
.\app\scripts\build_pack_resources.ps1 -SkipRuntime
```

### 第二步：生成解包目录

```powershell
cd $Repo\app\desktop
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
npm run pack:dir
```

或者直接调用：

```powershell
cd $Repo\app\desktop
.\node_modules\.bin\electron-builder.cmd --win --x64 --dir --publish never
```

输出：

```text
build\installer\output\win-unpacked\
```

### 第三步：压缩成便携 ZIP

```powershell
$out = "$Repo\build\installer\output\win-unpacked"
$zip = "$Repo\build\installer\output\OpinionLens-portable-0.1.0.zip"
if (Test-Path $zip) { Remove-Item $zip -Force }
Compress-Archive -Path (Join-Path $out '*') -DestinationPath $zip -CompressionLevel Optimal
Get-FileHash $zip -Algorithm SHA256
```

### 使用便携版

1. 解压 ZIP 到任意目录（建议 C: 本地盘）；
2. 直接运行：

   ```text
   OpinionLens.exe
   ```

3. 不需要安装，不写卸载器；登录态/数据仍使用 `%APPDATA%\OpinionLens`。

## 8. 常用清理命令

```powershell
# 停止正在运行的桌面 App
Get-Process OpinionLens -ErrorAction SilentlyContinue |
  Stop-Process -Force

# 清理 electron-builder 输出（谨慎）
Remove-Item "$Repo\build\installer\output" -Recurse -Force -ErrorAction SilentlyContinue

# 清理 Python 缓存
Get-ChildItem $Repo -Recurse -Directory -Filter '__pycache__' |
  Remove-Item -Recurse -Force -ErrorAction SilentlyContinue
```
