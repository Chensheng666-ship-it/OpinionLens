# 舆见 OpinionLens · Windows 安装包构建说明

> 版本：0.1.0（开源基线） · 更新日期：2026-11-12
> 构建机参考：Windows 10 x64，Node 20+/npm 10+，Electron 45.2.3，Python 3.11（uv 便携版）

## 1. 交付产物

| 产物 | 路径（仓库内） | 参考体积 | 说明 |
|---|---|---|---|
| NSIS 安装包 | `build/installer/output/OpinionLens-Setup-<version>.exe` | ~240 MB | per-user 安装，无需管理员；含便携 Python 运行时、sidecar（含采集动态 `/feed` 接口）、engine、MediaCrawler |
| 便携 ZIP | `build/installer/output/OpinionLens-portable-<version>.zip` | ~350 MB | 解压即用，免安装；带内置 Python 运行时 |
| 解包目录 | `build/installer/output/win-unpacked/` | ~900 MB | 安装包同源内容，便于排查 |

> 体积为历史构建参考值，随 MediaCrawler/依赖版本变化。构建脚本会打印实际产物的绝对路径、大小与 SHA256。

> 当前版本**未做代码签名**。首次运行可能出现 Windows SmartScreen / Defender 提示，需选择「更多信息 → 仍要运行」；
> 正式分发前建议配置代码签名证书。

## 2. 安装与运行

- 双击安装包，按向导选择安装目录（默认 per-user：`%LOCALAPPDATA%\Programs\OpinionLens`）。
- 自动创建桌面/开始菜单快捷方式；卸载默认保留用户数据。
- 用户数据目录：`%APPDATA%\OpinionLens\`
  - `logs\main.log`、`logs\sidecar.log`
  - `reports\`（生成的报告 HTML / meta）
  - `browser_data\`、`crawler\`、`exports\`
- **AI 报告为可选能力**：未配置模型 API 或调用失败时，报告中心自动使用本地模板生成（`degraded`），
  不影响采集与导出；多 LLM 模型 API 在「设置 → 模型 API」中配置。
- 采集浏览器使用**系统 Edge**（`channel="msedge"`），目标电脑需有 Edge（Win10/11 默认自带）；
  安装包未内置 Playwright Chromium。
- 网络受限/远程桌面/EDR 环境如遇 Electron 沙箱启动失败，应用会自动降级兼容启动（见 `app/README.md`）。

## 3. 重新构建

前置：Node/npm、MediaCrawler `.venv`（含依赖）、Python 基础运行时
（uv 路径 `%APPDATA%\uv\python\cpython-3.11-windows-x86_64-none`），磁盘 ≥ 3 GB（staging + 输出）。

```powershell
cd <仓库目录>

# 1) 生成 staging 资源（便携 Python + sidecar/engine/MediaCrawler/报告管线裁剪）
#    注意：只要改过 app/sidecar、app/engine、报告管线，就必须先跑这一步！
.\app\scripts\build_pack_resources.ps1

# 2) 打安装包（electron-builder，NSIS x64）
.\app\scripts\build_installer.ps1 -SkipResources

# 可选：只构建、不安装验证
.\app\scripts\build_installer.ps1 -SkipResources -SkipVerify
```

- `-SkipResources` 只用于「代码未变、仅重复打包」；**build_installer.ps1 会比对 staging 与最新源码，
  过期会直接中止**，避免把旧 sidecar 打进安装包。
- 安装验证阶段会自动校验安装产物 sidecar 是否包含源码中的 `/feed` 接口与 `run_feed.py`。
- 安装包输出在 `build/installer/output/`，构建脚本打印绝对路径、大小与 SHA256。
- 报告统计/模板管线（`app/report_pipeline`）正在从旧 POC 目录迁移到 app 下：打包脚本对该资源做
  存在性容错，缺失时只告警不中断；迁移完成后会自动打入安装包并在验证阶段强校验。

### 版本号

修改 `app/desktop/package.json` 的 `version` 后重新执行第 2 步即可（产物名含版本号）。

### 常见构建/安装问题

| 现象 | 处理 |
|---|---|
| npm/electron 下载慢或 502 | 构建脚本已默认使用 npmmirror（`ELECTRON_MIRROR` / `ELECTRON_BUILDER_BINARIES_MIRROR`）。安装包里的 Electron 直接取 `app/desktop/node_modules/electron/dist`（`electron-builder.yml` 的 `electronDist`，由 `npm ci` 按包内 `checksums.json` 校验），不会再从镜像二次下载 |
| 构建报 `node_modules\electron\dist 版本 … 不一致` | dist 与锁定的 electron 版本不符：在 `app/desktop` 重新执行 `npm ci` |
| 构建报 `Lock file is already being held` | 上次 electron-builder 被强杀留下的锁：删除 `%TEMP%` 下 `eb-dl-*.lock.lock` 目录后重试 |
| 安装后「采集动态」提示接口暂不可用 / Not Found | **staging 过期**（先跑过 `-SkipResources`）。跑 `build_pack_resources.ps1` 重新生成 staging 后重打安装包；构建脚本会拦截过期 staging |
| 安装失败 / “Failed to uninstall old application files” / 卡在旧版本卸载 | 旧版本卸载器异常或卡死。安装器已：① 在 `.onInit` 用 64/32 位注册表视图清理旧卸载登记、跳过旧卸载器；② 结束遗留 `old-uninstaller.exe` / `Un_A.exe`；③ 兜底忽略旧卸载器返回码。若仍失败，请附错误弹窗截图（或换一个空目录重试） |
| NSIS 安装静默 `/S` 很慢/卡在解压 | 不要安装到网络盘/透明加密盘；默认装到 C: per-user 目录 |
| 安装后窗口白屏 | 常见为 Chromium GPU/EDR 兼容问题；应用已有兼容回退，仍失败时查看 `%APPDATA%\OpinionLens\logs\main.log` |
| 报告中心显示未连接 | AI 报告为可选能力：未连接时自动走本地模板，不阻塞生成；如需 AI 叙述请在「设置 → 模型 API」中配置模型服务 |

## 4. 已验证清单

以下为构建/安装链路的关键验证项（建议每次发版复验）：

- [ ] `build_pack_resources.ps1` 生成 staging，`build-info.json` 时间戳晚于全部源码
- [ ] 打包后 sidecar 从 `resources/runtime/python` 启动成功，`/health` 通过，engine 路径 `resources/engine/entry.py`
- [ ] NSIS 安装包 `/S` 静默安装到空目录 exit=0
- [ ] 安装产物含采集动态接口：`resources/sidecar/run_feed.py` 存在、`main.py` 含 `/api/runs/{run_id}/feed`
- [ ] **旧版本异常升级回归**：伪造「旧卸载器返回非 0」的 HKCU 旧安装登记 + 旧安装目录，新安装器仍 exit=0
- [ ] **原地升级回归**：对已安装版本再次 `/S` 安装 exit=0
- [ ] 安装后 `OpinionLens.exe --screenshot <png>` 成功；sidecar 就绪
- [ ] 桌面/开始菜单快捷方式、卸载项、卸载保留用户数据（NSIS 配置）
- [ ] 安装包含 `runtime/python`、`sidecar/main.py`、`engine/entry.py`、`MediaCrawler/main.py`
- [ ] 数据目录为 `%APPDATA%\OpinionLens`（首次启动生成配置模板与日志）

## 5. 已知限制

1. **未签名**：SmartScreen/部分 EDR 会拦截，需要人工放行；正式发布建议购买代码签名证书。
2. **不内置 Chromium**：依赖系统 Edge；目标机没有 Edge 时采集不可用。
3. **不含 AI 后端/模型**：AI 报告需要用户自行在「设置 → 模型 API」配置模型服务；
   未配置时报告走本地模板。
4. 便携 ZIP 无快捷方式/卸载项，适合临时试用；代码更新后需要重新生成。
5. MediaCrawler 为非商业学习许可，本仓库不随附其源码；请勿将本工具用于商业分发或数据倒卖，
   详见根目录 `THIRD_PARTY_NOTICES.md`。
6. 升级安装会跳过旧版本卸载器（为避免旧卸载器卡死/失败）：旧安装目录可能残留文件，
   新安装目录不受影响；如需彻底清理可手动删除旧目录。
